OVERVIEW: The Endurance® Round Base Molded Table is designed for maximum durability and
functionality in demanding environments. Manufactured to ISO Quality Standards in the USA.
FABRICATION/MATERIAL: Table top and base are rotationally molded from high-impact “no break” polyethylene
for long-lasting strength. Sound dampening, easy to clean, sanitize, and maintain. Flame Retardant (passes UL 94
HB and Cal 133). Test reports available upon request.
COLOR Aqua, Black, Blue Gray, Brown, Burgundy, Canvas, Claylight, Gray, Green, Indigo, Midnight Blue, Moss,
Overcast, Sand, Seagrass, Slate Blue, Stone Gray and Tide. Custom colors available upon request.
DIMENSIONS 29H x 42W x 42D
Table Top Size: 42" diameter
WEIGHT: 38 lbs
Table Top: 22 lbs / Base: 16 lbs
OPTIONS Can be paired with the RazorBack Chair.
ASSEMBLY: Base attaches to table top with tamper-resistant screws. Can be bolted to the floor via concealed pilot
holes with the exclusive Sabre Mount System.
TESTING ISO 22196 tested showing a >99% reduction in bacteria.
WARRANTY Lifetime Warranty.
MAINTENANCE Easy to clean, sanitize & maintain.




Warranty valid on manufacturing defects only. Specifications subject to change without notice. Final dimensions & mounting holes
